# Code of Conduct

Iustitia contributors, maintainers, issue reporters, and reviewers are expected to help keep the project welcoming and technically honest.

## Expected behavior

- Be respectful, specific, and constructive.
- Assume good intent while still asking for evidence.
- Distinguish a detector result from a claim about a person.
- Discuss code and behavior, not someone's identity or competence.
- Explain disagreements with technical reasoning and reproducible examples.
- Credit research, references, and prior contributors.
- Disclose AI assistance when submitting code or documentation.
- Protect private server, player, and account information.

## Unacceptable behavior

- Harassment, threats, discrimination, doxxing, or targeted accusations.
- Publishing private logs, personal information, credentials, or server details without consent.
- Submitting knowingly unsafe, malicious, or deceptive code.
- Hiding a known false positive or compatibility limitation.
- Falsifying test results, live verification, benchmarks, or reproduction steps.
- Using an AI agent to mass-submit low-effort issues or pull requests.
- Attempting to turn Iustitia into a remote reporting, banning, or server-interference tool without an explicit project decision.

## Enforcement

Maintainers may edit, hide, close, or remove content and may restrict participation when needed to protect contributors or users. Serious or repeated violations may result in a ban from project spaces.

If possible, report conduct concerns privately to the maintainers rather than escalating them in a public thread.
